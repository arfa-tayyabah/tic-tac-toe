# Tic Tac Toe

A classic two-player Tic Tac Toe game.

## How to Play

1. Players take turns clicking empty squares
2. Player X goes first
3. Get 3 in a row (horizontal, vertical, or diagonal) to win
4. If all 9 squares fill with no winner, it's a draw

## Features

- Two-player gameplay
- Win detection with highlight
- Draw detection
- Game reset button

## Technologies

- HTML
- CSS
- JavaScript

## How to Run

1. Clone the repository
2. Open `index.html` in your browser
